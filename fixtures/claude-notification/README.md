Stdout frames of a real `claude` 2.1.326 run (Haiku, `--print --input-format stream-json`), recorded 2026-11-17. Each turn message was written with its own `uuid`, so the CLI reports its `command_lifecycle` (`__PROMPT_1__`, `__PROMPT_2__`). `init` frames are reduced to their session id and model; hook, rate-limit, commands-changed and thinking-progress frames are dropped.

- `queued-behind`: the first turn starts a background `sleep 6`, replies `STARTED` and ends. The task finishes, and its `task_notification` wakes the CLI into a turn of its own. The second message, written then (`prompt-2-written`), is `queued` behind it; the CLI answers the notification with its own result, then reports the message `started` and answers it (`BANANA`). The notification's result is not the second turn's.
